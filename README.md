# Initialize a Terraform Working Directory

This is a companion repository to the ["Initialize a Terraform Working Directory"](https://developer.hashicorp.com/terraform/tutorials/cli/init) tutorial.

## My notes
- `terraform init` downloads providers and modules and sets up the backend
- It creates the `.terraform/` folder and the `.terraform.lock.hcl` file
- Run it again whenever providers or modules change
